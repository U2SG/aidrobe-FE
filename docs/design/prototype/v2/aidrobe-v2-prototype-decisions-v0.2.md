# Aidrobe V2 原型决策 v0.2

## 1. Today 唯一基准

开发仅引用 `aidrobe-v2-today-selected.png`。最终规则为：暖白页面背景、白色主决策卡、暖色衣物展示区、卡内普通项目符号推荐理由、卡外轻量洞察提示行，并使用弱强调的灯泡图标。

其他 Today 候选稿归为探索历史，不参与实现与验收。

## 2. Context Override 层级

展开“今天有什么特别的吗”后，优先展示四个建议项：有会议、想舒服一点、不穿裙子、要走很多路。建议项置于上方并具备更高点击显著性。

自由输入置于“还可以打字”分隔线下方，默认空白、无光标、无预填示例文案，作为次要补充路径。

## 3. Onboarding 六步模型

1. Welcome — 1/6
2. Add Wardrobe — 2/6
3. Import / Confirm / Recovery — 3/6
4. First Outfit / Slot Gap — 4/6
5. Style Memory — 5/6
6. Departure Time — 6/6

同一步内的处理、确认与异常恢复沿用相同进度编号，不额外增加步骤。

## 4. 文件治理

修订内容已经直接覆盖原稳定文件名。本目录不保留 `rev1` 副本，开发只需按原型索引读取文件；历史稿不纳入实现目录。
