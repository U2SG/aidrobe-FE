# 衣然 YIRAN Logo v1

状态：选定方案 C「柔和叠影」后的首版正式资产。

## 资产

- `yiran-mark-primary.svg`：主标志，透明背景
- `yiran-mark-primary-1024.png`：主标志位图，透明背景
- `yiran-mark-monochrome.svg`：单色标志，透明背景
- `yiran-mark-monochrome-1024.png`：单色标志位图，透明背景
- `yiran-lockup-horizontal.svg`：中英横版组合标志
- `yiran-app-icon.svg`：1024 × 1024 App Icon 矢量源文件
- `yiran-app-icon-1024.png`：1024 × 1024 App Icon 位图

## 设计含义

三片形状分别代表衣物、当日情境与个人偏好。它们不是菜单式选项，而是围合成一个完整决定；中央留白表达「衣然 = 依然是我」。

## 色彩

| 用途 | 色值 |
|---|---|
| 暖白背景 | `#FAF7F0` |
| 主墨色 | `#1A1714` |
| 暖金强调 | `#B08D5B` |
| 暖金浅色 | `#F4E8D1` |

## 使用规则

- 标志四周最小留白为标志宽度的 `1/6`。
- 彩色标志最小数字尺寸建议 `32px`；更小时使用单色版。
- App Icon 保留完整方形背景，由平台统一裁切圆角。
- 不添加渐变、投影、描边或额外装饰。
- 不改变三个形状的相对位置、旋转角度和色彩顺序。
- 横版组合中的文字在交付印刷或商标文件前应转换为轮廓。

## 状态说明

该版本可用于产品视觉验证。商标正式发布前仍需完成名称与图形近似查重。
