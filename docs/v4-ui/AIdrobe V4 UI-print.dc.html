新增第 4 个「发现」tab，作为工具 + 洞察聚合页

4 个工具型功能（打包 / 灵感 / sense-check / 报告）没有自然落点。塞进现有 tab 会让「今日」「衣橱」过载；分散落位则发现性差。一个聚合 tab 既给它们家，又顺势解决「入口聚合」的问题。
